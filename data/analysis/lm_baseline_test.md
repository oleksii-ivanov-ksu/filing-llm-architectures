# C3 — Скалярний бейзлайн Loughran-McDonald → BL vs метод → BL (RQ3)

*core+holdout, 2006–2025, стратегія `bl_llm_tilt_pos`, 10 випадкових поділів 50/50
(seed 42). Дата: 2026-09-04. $0 API. Словник: pysentiment2 (LM word lists, 140 pos /
893 neg стемів).*

## Питання (RQ3)
Чи несе структуроване багатовимірне LLM-вилучення більше downstream-цінності, ніж
**один сентимент-скаляр** того ж документа? Той самий конвеєр BL+tilt; відрізняється
лише джерело view.

## Метод бейзлайну
Для кожного філінгу: тон = (#pos − #neg)/(#pos + #neg) за словником LM на тих самих
секціях (Risk/MD&A/Liquidity/Business, ≤80k токенів). Крос-секційний z-score тону на
кожну дату → view_bps (той самий clamp [−300,300]), confidence="medium". Далі — той
самий бэктест. Скрипт: `scripts/v2/run_lm_baseline.py` (+ `compare_lm_vs_method.py`).
8001 views, 0 невдач.

## Результат

Sharpe — канонічний (rf=2%, стандарт движка й методу-v1). Річна дохідність — без rf.

| Джерело | Sharpe (10 поділів) | Річна дохідність |
|---|---|---|
| **LM-скаляр** | 0.483 | 13.6% ± 2.4% |
| 2-стадійний метод | 0.517 | 15.0% ± 1.4% |
| 1-стадійний метод | 0.520 | 15.2% ± 2.1% |

*(«сирий» Sharpe без rf для тих самих серій: LM 0.651 / 2-stage 0.682 / 1-stage 0.684 —
ті самі гепи; для статті використовуємо канонічні числа з rf=2%.)*

**Paired t-test per-split Sharpe (метод − LM):**
- **2-stage − LM:** ΔSharpe +0.030 ± 0.053, t=1.71, **p=0.121** (н.з.), виграє 8/10
- **1-stage − LM:** ΔSharpe +0.032 ± 0.041, t=2.39, **p=0.040** (значуще), виграє 7/10

## Висновки
1. **Словниковий тон — сильний бейзлайн** (Sharpe 0.65 > Equal-Weight ~0.50). Основна
   цінність надходить від самого «сигнал із тексту → BL-tilt», а не від складності
   вилучення.
2. **Багатовимірне вилучення додає невеликий, але реальний приріст** над скаляром:
   +0.03 Sharpe, +1.4–1.6 пп річних. Значущий для одностадійної (p=0.04),
   маргінальний для двостадійної (p=0.12).
3. **Одностадійна знову попереду** — саме її перевага над LM статистично значуща.
   Узгоджується з E2 (alpha 9/10) і C5 (rank-IC 0.056 vs 0.014).
4. Це **посилює чесність статті**: метод б'є класичний словниковий підхід, але
   скромно; ми не переоцінюємо LLM.

## Застереження
- **Звірку абсолютного Sharpe знято.** Раніша розбіжність (0.68 vs 0.52) — це «сирий»
  Sharpe vs канонічний з rf=2%. Канонічні числа (0.483/0.517/0.520) збігаються з E2/E3.
  Надалі всі скрипти рахують Sharpe через `src.backtesting.metrics.sharpe_ratio`.
- Словник pysentiment2 — стеммована версія LM; для статті зафіксувати версію словника.
