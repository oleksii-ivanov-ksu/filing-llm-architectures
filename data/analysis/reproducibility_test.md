# C4 — Відтворюваність extraction (інженерна стабільність)

*Schema-v2 extraction, модель `google/gemini-2.5-flash`, T=0.1 (продакшн), 3 прогони на
однаковому фіксованому наборі — 90 документів gold-standard manifest. Дата: 2026-09-04.
Вартість ~$4.4. Скрипт: `scripts/v2/run_reproducibility.py`. Результат:
`data/v2/analysis/reproducibility.json`.*

## Питання
Наскільки стабільний конвеєр між незалежними прогонами при робочій температурі —
тобто чи можна довіряти одному прогону корпусу (правило «один прогін»).

## Метрики згоди між 3 прогонами (на документ, усереднено по 90)

| Метрика | Значення | Інтерпретація |
|---|---|---|
| Jaccard категорій ризиків (сер. попарний) | **0.856** | набір категорій ризиків збігається на ~86% |
| Згода sentiment (усі 3 однакові) | **88.9%** | у 89% док. загальний тон ідентичний |
| Згода напрямку guidance | **84.4%** | напрямок прогнозу стабільний |
| Сер. std кількості ризиків | **0.36** | коливання < ½ фактора |
| Сер. std кількості подій | **0.90** | коливання ~1 подія |
| Сер. std частки grounded | **0.0** | обґрунтованість детерміністично стабільна |

## Висновки
1. **Конвеєр добре відтворюваний** при T=0.1: категоріальні факти (категорії ризиків,
   sentiment, напрямок guidance) збігаються на 84–89%; лічильники фактів «пливуть»
   менш ніж на одну одиницю.
2. **Grounding — детерміністичний** (std частки = 0): правило «не обґрунтовано → не
   існує» дає стабільний фільтр незалежно від прогону.
3. Це **обґрунтовує правило одного прогону корпусу**: залишкова варіативність мала й
   зосереджена в «хвостових» фактах (рідкісні події), а не в основному сигналі.

## Застереження
- Вимірювано на рівні extraction; варіативність фінального `view_bps` після reasoning
  тут не оцінювалась окремо (reasoner детерміністичніший, бо працює вже над
  відфільтрованими фактами) — за потреби додати як окремий підпункт.
- 90 документів gold-manifest стратифіковані за сектором/періодом/формою — репрезентативні
  для корпусу, але не весь корпус.
